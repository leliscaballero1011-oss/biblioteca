# Sistema de Gestión de Biblioteca (CRUD Autor y Libro)

Proyecto independiente desarrollado en Java con Maven y SQLite mediante JDBC, aplicando arquitectura en capas, interfaces DAO e implementaciones con buenas prácticas de validación de excepciones.

## Tecnologías Utilizadas
* Java (Maven)
* SQLite (JDBC)
* NetBeans IDE

## Estructura del Proyecto
* `src/`: Código fuente separado por capas (modelo, DAO, implementación, servicios y aplicación).
* `biblioteca.sql`: Script de creación y configuración de la base de datos.
* `evidencias/`: Carpeta que contiene las capturas de pantalla de las pruebas del sistema.
